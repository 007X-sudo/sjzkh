# 学生信息管理系统 · 使用说明

## 1. 先看网页

双击本目录的“学生管理系统预览.html”，用较新的 Edge、Chrome 等浏览器打开。无需先安装 Python，也无需联网下载资源。

页面默认使用本地预览模式，首次显示五名虚构学生，可直接尝试添加、编辑、删除、按完整学号查找，以及四种成绩的升降序排序。操作保存在当前浏览器；换浏览器、换设备或清除浏览器数据不会保留这些记录。

页面适配手机窄屏，宽表格可左右滑动。手机访问属于独立的浏览器预览；本次提供本地文件，尚未发布公网链接。

## 2. 启动纯 Python 后端

安装 Python 3.8 或以上版本，无需 pip 安装任何包。

在 backend 文件夹空白处右键，选择“在终端中打开”，运行：

```powershell
python app.py
```

若提示找不到 python，可尝试 py app.py，或检查安装时是否勾选 Add Python to PATH。终端保持打开，按 Ctrl+C 停止服务。

回到 HTML 的“使用说明”页面，点击“连接 Python 后端”。电脑端也可以点击侧栏同名按钮。若浏览器询问是否允许访问本机服务，请允许。

连接成功后，模式标记会变为“Python 后端”，操作实际保存到 backend/data/students.json。该文件在首次启动时自动创建，包含五名示例学生。

**预览模式与 Python 后端各自保存一套数据，不会自动互相导入。** 后端只监听本机 127.0.0.1:8000。手机不能通过该地址连接电脑；公网部署不属于本次预览交付。

## 3. 业务规则

- 学号唯一；姓名、学号、班级不能为空。
- 语文、数学、英语各为 0–100 分，可输入小数。
- 总成绩由三科相加实时计算，显示保留最多两位小数，不写入 JSON。
- 按完整学号精确查找；可按语文、数学、英语、总成绩升序或降序排列。
- 编辑时自动带入原值，不修改的字段保持原值。
- 删除前必须确认；新增、修改、删除成功后立即保存。

## 4. Python 文件对应关系

- app.py：HTTP JSON API 入口，不提供前端页面。
- models.py：学生模型、字段校验、总分计算。
- repository.py：首次五人初始化、JSON 文件读写。
- service.py：增删改查、唯一学号、精确查询和排序。
- tests/test_service.py：业务层及 HTTP API 自动化测试。

Python 后端源码.zip 仅包含 Python 代码文件，不含 HTML、CSS、JavaScript 或第三方依赖。独立的 HTML 已内嵌其前端资源，可单文件预览。preview 子目录保留可阅读的 HTML 模板和 JavaScript 源文件；日常使用只打开根目录的完整预览文件即可。

## 5. API 速查

请求/响应均为 JSON。字段为 student_id、name、class_name、chinese、math、english；返回的学生对象另含实时计算的 total。

| 方法 | 路径 | 功能 |
|---|---|---|
| GET | /api/health | 运行状态 |
| GET | /api/students | 全部学生 |
| GET | /api/students?student_id=2026001 | 按完整学号查询 |
| GET | /api/students?sort_by=total&order=desc | 按总成绩降序 |
| GET | /api/students/2026001 | 获取一名学生 |
| POST | /api/students | 新增学生，提交六个基础字段 |
| PATCH | /api/students/2026001 | 修改学生，只提交需要改动的字段 |
| DELETE | /api/students/2026001 | 删除学生 |

sort_by 可取 chinese、math、english、total；order 可取 asc、desc。输入错误返回 400，不存在返回 404，重复学号返回 409。

## 6. 自己运行测试

在 backend 文件夹的终端执行：

```powershell
python -m unittest discover -s tests -v
```

测试使用临时文件，不修改实际的学生数据。
