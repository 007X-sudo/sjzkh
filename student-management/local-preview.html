A SMALL GUIDE TO GET STARTED.

使用说明

依据 README 的业务要求，用网页完成同样的管理操作。

先预览，再连接后端

  1. 直接打开本 HTML，默认进入本地预览，首次提供五名虚构学生。可新增、编辑、删除、搜索和排序。
  2. 启动后端：在 backend 文件夹打开终端，执行 python app.py。
  3. 点击下方或侧栏的“连接 Python 后端”。连接成功后，操作会通过 API 保存到 backend/data/students.json。
  4. 后端仅监听 127.0.0.1:8000，适合本机课程设计演示。不要把本地 API 地址当成可分享给手机的公网服务。

业务规则

  • 学号必须唯一，姓名、学号、班级不能为空。
  • 每科成绩为 0–100 的数字，总成绩为三科实时相加。
  • 按完整学号精确查询；支持语文、数学、英语、总成绩的双向排序。
  • 编辑弹窗会带入原值，不改动的字段保持不变；删除前需要确认。
  • 写入后端时立即保存基础字段，JSON 不单独存储总成绩。
预览模式与后端模式使用不同的数据，不会自动互相导入。Python 文件仅包含数据模型、业务逻辑、JSON 存储与 API，没有 HTML / CSS / JavaScript。当前页面为设计预览，尚未发布到任何网站。
